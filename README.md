# Gem Infinity — luxury redesign (React + Vite + three.js)

    npm install
    npm run dev      # development
    npm run build    # production build in dist/

Pages: /, /about, /projects, /gallery, /contact and /sree-sreenivasa-county (+ /amenities, /gallery, /layout, /location).
Theme: white + sky blue — tokens at the top of `src/theme.css`. Hero building is built procedurally in `BuildScene` (`src/scenes.jsx`).
All copy, figures and image URLs live in `src/data.js`.
